## 🚀 Sprint 1: "Engineering as Marketing" (Viral On-Site Free Utilities)
*High-intent interactive tools hosted directly on the site to attract students searching for career advancement and salary benchmarks.*

- [x] ~~**MKT-1.1: Data Analyst Salary & Career Hike Calculator**~~ *(Completed & Deployed on staging)*
  - **Goal:** Allow visitors to enter current salary (e.g., ₹3.5 LPA in BPO/Support/Fresher) and target stack to calculate projected post-course package (₹7.5 - ₹12 LPA) and monthly in-hand take-home.
  - **Conversion Hook:** Generates an interactive "Skills Gap Analysis" highlighting required competencies (SQL, Power BI, Python, GenAI) with direct one-click jump to The Data Pilot enrollment.
  - **Estimated Effort:** 1-2 days.

- [ ] **MKT-1.2: Data Analyst Resume ATS Keyword Evaluator**
  - **Goal:** A lightweight tool where job seekers paste their resume to score compatibility against top analytics recruiters (Deloitte, TCS, Fractal, Accenture).
  - **Conversion Hook:** Highlights missing high-value keywords (Window Functions, DAX, CTEs, Data Pipelines) and links to portfolio projects built in the bootcamp.
  - **Estimated Effort:** 1-2 days.

- [ ] **MKT-1.3: Natural Language to SQL Query Generator**
  - **Goal:** Free utility where beginners type plain-English questions to generate optimized SQL syntax.
  - **Conversion Hook:** Watermarked query results with link to the 16-week live instructor-led SQL module.
  - **Estimated Effort:** 2 days.
